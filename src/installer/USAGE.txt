《真名法典2》简体中文汉化补丁 v1.0
玩家使用说明

这份说明适用于本文件所在目录中已经生成的汉化游戏。
安装完成后，无需再次运行补丁程序；按下列方法打开生成的游戏即可。

{{#zar}}
一、启动游戏（ZAR）
1. 保留 {{OUTPUT_NAME}}_Disc1.zar 和 {{OUTPUT_NAME}}_Disc2.zar，两份放在同一文件夹。
2. 启动支持 ZArchive 的 Xenia Canary / Edge，选择 File → Open（文件 → 打开）。
3. 选择 {{OUTPUT_NAME}}_Disc1.zar，进入游戏。不要打开原版 ISO，也不要解压 ZAR。
4. 更换电脑时，复制两份 ZAR 即可；存档请从原模拟器另行备份和迁移。

二、换碟
游戏要求换碟时，保留模拟器会话，等待其弹出的换碟文件选择窗口，
选择 {{OUTPUT_NAME}}_Disc2.zar。不要将第二盘当作新游戏重新启动。
本作两盘的完整换碟流程尚待实测，请提前备份存档，不要覆盖唯一存档。
{{/zar}}
{{#xex}}
一、启动游戏（XEX 文件夹）
1. 保留 Disc1 和 Disc2 两个文件夹，以及各自内部的完整目录。不要合并两盘文件。
2. 使用 Xenia：选择 File → Open（文件 → 打开），打开 Disc1/default.xex。
3. 使用 Xbox 360 RGH / JTAG：将 Disc1 和 Disc2 完整复制到硬盘的同一游戏目录下，
   用主机文件管理器启动 Disc1/default.xex，或将两盘目录加入所用启动器的扫描路径。
4. 移动游戏时要复制整个 Disc1、Disc2 文件夹，不能只复制 default.xex。

二、换碟
游戏要求换碟时，在模拟器弹出的换碟文件选择窗口中选择
Disc2/default.xex。主机启动器请为本作启用其多碟管理，并保留两盘目录独立。
本作完整换碟流程及各主机启动器的行为尚待实测，请先备份存档，不要覆盖唯一存档。
{{/xex}}

{{#dlc}}
三、安装本次生成的 DLC
输出目录的 Content/0000000000000000/4E4D0811/00000002/ 中有两个文件：
  18B8C8A148D63B0BAFE42CF63E203D482BE029C24E — 短剧包（全 3 集）
  A6075CF4FC20724B15DA064AB2FCAB16B1CCC3FD4E — 特殊武器包（全 12 种）

使用 Xenia Canary / Edge：
1. 在模拟器中找到 Install Content（安装内容；依版本位于 Content 或 File 菜单）。
2. 依次选择上述两个“本次输出”的文件，等待各自安装完成。
3. 重新进入游戏，检查短剧列表和特殊武器是否出现。若没有出现，请核对安装到的
   是否为正在使用的模拟器；不要把 Content 放进 Disc1/Disc2 或 ZAR 内。

使用 RGH / JTAG 主机：
将输出 Content 内的 0000000000000000 文件夹合并复制到 HDD1:/Content/，最终保留
HDD1:/Content/0000000000000000/4E4D0811/00000002/两个包文件 的目录层级。
不要覆盖或删除其他游戏、用户档案和存档；实机 DLC 识别仍需确认。
{{/dlc}}
{{#no_dlc}}
三、DLC
本次未生成 DLC，输出目录没有 Content 文件夹。若需要汉化短剧和特殊武器，
重新运行补丁程序，启用“同时汉化 DLC”，选择原版两个 DLC 所在的 00000002 文件夹，
并使用一个新的输出目录。原游戏目录和已有存档无需删除。
{{/no_dlc}}

四、继续旧存档、更新和移除
请继续使用原来的模拟器用户档案与存档位置。补丁程序没有搬动或修改你的存档。
换电脑、更新补丁或尝试换碟前，先备份存档。更新时使用新的游戏输出目录，
不要将不同版本或原版资源混在一起。确认新版本可以读取存档后，再处理旧游戏目录。
移除本补丁只需删除本次生成的游戏目录；模拟器、配置、用户档案和存档应继续保留。

五、遇到问题
画面不是中文：检查打开的是本次生成的 Disc1，而不是原版 ISO 或旧快捷方式。
游戏打不开：保留本目录的“安装结果.json”，记录模拟器版本、报错和复现步骤。
DLC 未出现：按第三节检查两个输出包是否都已安装到当前使用的模拟器或主机。
反馈时附截图及“安装结果.json”；公开文件前可检查其中的本机路径信息。
