# 阶段371：右下角数量／技能数字描边

截图中 X 键旁的数量字芯为白色，旧字图只有右下投影。与相邻汉字的黑边对齐，
本轮在 MC2Game 驻留的 Font.General_15 的 0–9 数字周围加入一原生纹素黑边。
Selected.KanNum 与展开时的四个 KanNum renderer 已绑定该字体。
共享同一份驻留字体的其他消费者也会看到新版半角数字；其他物理字体副本不改。

输入为阶段370 MC2Game（SHA256 076d165efe18b64d36b5106dc3913aada71ff80f790ee56a7c77a87d7477408b）。
用 `tools.font_shadow --outline` 和 `locales/zh-Hans/hud-digit-outline-v41.json`
重建。颜色与覆盖率必须经过实际 BC3 回读；原有白芯和黑投影保持逐像素一致，
不改变字宽、高度、数值、位置或邻近汉字。只改 122 个块，新增 484 个黑边像素，无裁切。

实际解码对照、修改资源、差异、验证记录和独立副本回滚在
`build/phase-371-hud-outline`。现有中文测试入口用于先看游戏画面；本轮不重打安装器，
不新建 ISO／完整游戏副本。实机观感与解码预览分开验收。
